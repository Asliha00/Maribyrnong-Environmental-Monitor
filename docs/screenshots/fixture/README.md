# Screenshots of SYNTHETIC test data

These images are regenerated by the Playwright suite (`e2e/dashboard.spec.ts`, `insights.spec.ts`,
`login.spec.ts`) from the
invented fixture database (`backend/scripts/make_fixture_db.py`). Sensor names (FX-…),
values and alerts are **not** council data and must not be quoted as findings.
They exist to show layout at 1366×768 and tablet size. Screenshots of the real data for the
user manual are captured in Phase 8.

| File | Shows |
|---|---|
| `login_{light,dark}_{1440,768,390}.png` | Login page in both themes at desktop, tablet and phone width (illustration hidden on phones) |
| `login_contrast.json` | Measured WCAG contrast of the login page text, link and button, both themes |
| `login_forgot_password_1366.png` | "Forgot password?" help, reached by keyboard |
| `dashboard_1366x768.png`, `dashboard_tablet_768x1024.png` | Dashboard (Analyst) |
| `insights_1366.png` | Insights page (Analyst) |
